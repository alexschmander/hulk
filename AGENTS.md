# Agent entry points

For simulator control, ROS-Z state inspection, or visual inspection through MCP, start with the [simulator MCP guide](tools/simulate/README.md#agent-access-through-mcp). It covers client setup and the workflow for an owned headless session.

When changing the simulator MCP server, read the [design and limitations](docs/tooling/simulator_mcp_design.md) and [tool contract](docs/tooling/simulator_mcp_contract.schema.json). The guide includes the integration test command.
